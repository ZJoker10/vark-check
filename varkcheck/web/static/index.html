    How this works, and what it does not do

    It summarises, it does not excerpt

    Every sentence is rewritten and merged across sections, then checked in code against your material: if too much of the report is close to verbatim source wording, it is sent back once and rewritten. Each claim carries the source it came from.

    The profile is a hypothesis

    Matching teaching to a preferred learning style has weak evidence behind it (Pashler et al., 2008). The report is shaped by how you described yourself because that is a reasonable place to start — not because you have been diagnosed.

    Nothing is stored about you

    No account, no cookie, no analytics. Your answers stay in this browser's local storage. The uploaded text lives in the server process's memory and expires after two hours.

    Images are embedded, not read

    Pictures in your material are placed in the report as figures with their captions. Their contents are not interpreted, because there is no vision model in this build. Scanned PDFs with no text layer need OCR, which is also not included.

    Runs locally. Your material is sent only to the model you configured.
